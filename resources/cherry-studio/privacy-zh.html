Cherry Lite 隐私协议

更新日期：2026年8月16日  生效日期：2026年8月16日

欢迎使用 Cherry Lite（以下简称“本软件”）。本软件是运行在您设备上的本地桌面应用。我们不运营账号系统，也不收集、上传您的对话内容或 API Key。

一、我们不收集的信息

本软件不会收集、保存或上传：

  • 您填入的模型服务 API Key；
  • 对话、翻译正文，以及本机上的话题、附件、偏好；
  • 可识别个人身份的信息；
  • 匿名使用统计、功能埋点、崩溃上报（完整版里的这类开关已从本分叉移除）。

因此设置里也没有「隐私数据收集」开关——没有对应的上报通道。

二、数据存在哪里

  • API Key、历史对话、翻译记录、偏好设置都只存在本机。
  • 备份只有本地备份 / 恢复 / 导入，没有 WebDAV、S3、坚果云，也没有 Notion、语雀、Joplin、Obsidian、思源笔记等导出。
  • 本软件不提供云同步。您可以在「设置 > 数据」查看数据目录、做本地备份，或改存储位置。

三、何时会联网

本软件作为本地工具，只在下列情况下出网：

  1. 模型调用：设备直接连接您配置的模型服务；
  2. 您主动打开的可选能力：网页搜索、MCP、OCR、文档处理等，凭证只在本机使用；
  3. 检查更新：访问本仓库的 GitHub Releases（loadchange/cherry-studio-lite）。

请勿利用本软件制作、复制、发布或传播违反您所在地法律法规的内容。

四、第三方服务

当您使用自己配置的模型或可选第三方能力时，数据由对应服务商按其隐私政策处理。本软件管不到那些采集行为。若要了解或关闭，请查阅该服务商的说明。

五、协议更新

协议若有实质变更，会通过版本说明或软件内提示告知，并更新本页日期。生效后继续使用，即视为知悉更新后的内容。

六、联系

疑问请到 GitHub Issues 反馈。

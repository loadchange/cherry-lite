Cherry Studio Lite Privacy Policy

Updated Date: August 16, 2026  Effective Date: August 16, 2026

Welcome to Cherry Studio Lite (“this Software”). It is a local desktop app. We do not run accounts, and we do not collect or upload your conversations or API keys.

I. Information We Do Not Collect

This Software does not collect, store, or upload:

  • Model-provider API keys you enter;
  • Chat or translation text, or local topics, attachments, and preferences;
  • Personally identifiable information;
  • Anonymous usage analytics, feature telemetry, or crash reports (those upstream switches are gone in this fork).

There is no in-app “privacy data collection” toggle, because there is no reporting channel to turn off.

II. Where Data Lives

  • API keys, chat history, translations, and preferences stay on this device.
  • Backup is local backup / restore / import only. There is no WebDAV, S3, Nutstore, or export to Notion, Yuque, Joplin, Obsidian, or SiYuan.
  • There is no cloud sync. Use Settings > Data to see the data directory, make a local backup, or move storage.

III. When the App Goes Online

This Software is a local tool. It talks to the network only for:

  1. Model calls to the provider you configured;
  2. Optional features you turn on (web search, MCP, OCR, document processing). Credentials stay local;
  3. Update checks against this repository’s GitHub Releases (loadchange/cherry-studio-lite).

Do not use this Software to produce or distribute content that violates the laws of your jurisdiction.

IV. Third-Party Services

When you use a provider or optional third-party feature you configured, that service processes data under its own privacy policy. This Software cannot disable those collections. Read that provider’s policy if you need details or an opt-out.

V. Policy Updates

Material changes will be called out in release notes or in-app notices, and the dates on this page will change. Continued use after the effective date means you have seen the updated terms.

VI. Contact

Questions: GitHub Issues.
